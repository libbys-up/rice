# Rice's documentation

- `developers-manual.tex`: the design of the compiler, the runtime, the
  collector and the backtracking optimizations, with their soundness rules.
  Start here.
- `style-guide.md`: coding and commenting conventions.
- `status.md`: where the project stands, and what's next.
- `plans/`: plans for work not done yet (`features-plan.md` lists the
  missing features and how to add them).
- `results/`: the measurements behind rice's defaults: the backtracking
  optimizations, and rice against KiCS2.
- `history/`: finished plans, the compiler's and runtime's histories, and
  old status snapshots and reviews. They explain why things are the way they
  are; the code and the manual say what they are now.

`../AGENTS.md` is the quick guide to building, testing and the rules for
heavy jobs.
