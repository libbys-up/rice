# Per-test overrides for tests/run.sh. One entry per line:
#
#   <relative-path-to-.curry>  <STATUS>  <reason...>
#
# STATUS is one of:
#   SKIP   never run (e.g. not meant to be compiled at all -- inspection-only
#          source, or a program requiring a feature with no plan to support it)
#   XFAIL  expected to fail (frontend rejects it, or compilation fails) for a
#          documented, pre-existing reason unrelated to Rice; run.sh reports
#          XPASS (not a hard failure, but worth noticing) if it starts
#          succeeding, so a real fix doesn't silently stay uncredited here.
#   SLOW   compiles and runs correctly but takes too long for a "run before
#          every commit" pass -- skipped unless run.sh is given --slow, then
#          run with a longer timeout.
#   XSLOW  a large-input benchmark that's *expected* to crash or time out
#          once actually run (not just slow) -- same "no trampoline or
#          backtracking optimizations yet" cause as STATUS.md's Phase 1/2
#          notes, confirmed via a real crash backtrace for at least one of
#          these (STATUS.md's own write-up). Skipped by default like SLOW;
#          under --slow, a compile failure/crash/timeout doesn't count as a
#          failure (XPASS if it unexpectedly runs clean instead, same
#          spirit as XFAIL -- worth noticing, not something to leave stale
#          here).
#
# Blank lines and lines starting with # are ignored. A path with no entry
# here uses run.sh's default timeouts and must match its own <name>.expected
# (if present) or just exit 0 without timing out (if not).

# --- kics2_bench/: KiCS2's benchmark suite (kics2/benchmarks/suite), each
# file's header says what (if anything) was changed for the modern

# both sides before unifying, so a candidate built from free variables

kics2_bench/NDNums.curry          SKIP   an infinite search space by design (all naturals): KiCS2 benchmarks it with a complete search strategy, which rice doesn't have
kics2_bench/Last.curry            XFAIL  times out: `xs ++ [x] =:= l` with rice's normalize-first (=:=) (see above); it prints its answer, then searches longer xs forever
kics2_bench/RegExp.curry          XFAIL  times out: grep's `xs ++ sem r ++ ys =:= s` with rice's normalize-first (=:=) (see above)
kics2_bench/SearchQueens.curry    XFAIL  times out: permute's `u++v =:= permute xs` with rice's normalize-first (=:=) (see above)
kics2_bench/SearchEmbed.curry     XFAIL  times out: `t =:= x++(c:ts)` with rice's normalize-first (=:=) (see above); KiCS2's own harness leaves this one out too
kics2_bench/SearchHorseman.curry  XFAIL  times out: `int2nat heads =:= m `plus` h` over free Peano naturals with rice's normalize-first (=:=) (see above)
kics2_bench/SearchGraph.curry     XFAIL  runtime error: "can't narrow a free variable to Int: it has a raw (unboxed) field" (inv's `a =:= g b` with b a free Int)
